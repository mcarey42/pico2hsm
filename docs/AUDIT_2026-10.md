# Security & memory audit — October 2026

Source: local reviews run 2026-10-10 against `fix/reset-deadlock-and-zeroize`
(security review, memory/async review, post-v1.0.0 diff review).
Status: `open` · `fixed <commit>` · `wontfix (reason)`.
