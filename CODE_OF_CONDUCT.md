# Code of Conduct

This project adopts the Contributor Covenant, version 2.1, as its code of conduct.
The canonical text is published at https://www.contributor-covenant.org/version/2/1/code-of-conduct/.

## Summary

Contributors agree to interact with other contributors in a respectful and
professional manner. Unacceptable behaviour will not be tolerated in any project
space (GitHub issues, pull requests, discussions, code review).

## Reporting

Report concerns to the maintainer privately via GitHub's security advisory
channel at https://github.com/mcarey42/pico2hsm/security/advisories (the same
channel used for security reports per `SECURITY.md`). Reports are handled
privately. Retaliation against reporters is itself a violation.

## Enforcement

The project maintainer is responsible for enforcement. Consequences range from
a private warning to a permanent ban, as described in the Contributor Covenant
enforcement guidelines (see the canonical URL above).
